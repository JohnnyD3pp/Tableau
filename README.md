# Tableau

Este repositório reúne estudos, práticas e projetos desenvolvidos com **Tableau**, com foco em visualização de dados, criação de dashboards e preparação de bases para análise.

O material está dividido entre arquivos do **Tableau Public**, voltados à construção de painéis interativos e análises visuais, e arquivos do **Tableau Prep Builder**, utilizados para limpeza, transformação e organização de dados antes da etapa de visualização.

## Conteúdos Abordados

- Criação de dashboards no Tableau
- Construção de gráficos e painéis interativos
- Análise exploratória de dados
- Indicadores e KPIs
- Visualização de vendas, lucro, clientes e produtos
- Análises geográficas
- Análise de jornada e comportamento do cliente
- Preparação de dados no Tableau Prep Builder
- Limpeza e padronização de bases
- União e organização de tabelas
- Criação de fluxos de tratamento de dados

## Como Abrir os Arquivos

Para visualizar os dashboards:

1. Instale o **Tableau Public** ou **Tableau Desktop**.
2. Baixe ou clone este repositório.
3. Acesse a pasta `Tableau Public`.
4. Abra o arquivo `.twbx` desejado.

Para visualizar ou editar os fluxos de preparação:

1. Instale o **Tableau Prep Builder**.
2. Acesse a pasta `Tableau Prep Builder`.
3. Abra o arquivo `.tflx` desejado.

## Observações

Arquivos `.twbx` são workbooks empacotados do Tableau e podem incluir dashboards, planilhas, dados e imagens utilizados na visualização.

Arquivos `.tflx` são fluxos empacotados do Tableau Prep Builder e podem conter etapas de limpeza, transformação e organização de dados.

Alguns arquivos representam versões intermediárias ou práticas específicas realizadas durante os estudos.

## Objetivo do Repositório

Este repositório tem como objetivo organizar práticas de **análise e visualização de dados com Tableau**, reunindo dashboards, estudos exploratórios e fluxos de preparação de bases para apoiar a construção de visualizações mais claras, estruturadas e orientadas à tomada de decisão.
